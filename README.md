# 🧮 BMI Calculator

Welcome to the **BMI (Body Mass Index) Calculator**!  
This simple and elegant web application helps you calculate your **BMI** based on your **height (in cm)** and **weight (in kg)**.

---

## 🌟 Features

- ✅ User-friendly interface
- 📏 Inputs: Height in **centimeters** & Weight in **kilograms**
- ⚙️ Real-time validation and result
- 🧠 Instant BMI calculation and health category comment
- 💡 Shows BMI guideline (underweight, normal, overweight)
- 🎨 Modern, responsive UI with styled hover effects

---

## 📌 How to Use

1. **Enter your height** in centimeters (e.g., `170`)
2. **Enter your weight** in kilograms (e.g., `65`)
3. Click the **"Calculate"** button
4. Instantly view your **BMI value** and a comment like _Normal Range_, _Underweight_, or _Overweight_

---

## 💻 Technologies Used

- 🧾 **HTML5**
- 🎨 **CSS3**
- ⚙️ **Vanilla JavaScript (DOM manipulation)**
